## ✨ Key Features

- **Pixel-Perfect Rendering:** Uses CSS crisp-edge scaling to keep pixel art sharp across all device resolutions.
- **Dynamic Catalog:** Data-driven gallery architecture powered by dynamic data structures.
- **Category Filtering:** Seamless categorization (Music, Animation, Pop Culture, Gaming, Animals, Originals).
- **Interactive Lightbox Modal:** Full-view modal with artwork specifications, dynamic captions, and keyboard navigation (`←`, `→`, `Esc`).
- **Dark Retro Aesthetic:** Arcade-inspired palette engineered to maximize visual contrast.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic layout and accessibility metadata.
- **CSS3:** Custom styles, flexbox grid, backdrop filters, and pixelated image rendering.
- **JavaScript (Vanilla ES6+):** Dynamic DOM rendering, filtering logic, and keyboard event handling.
